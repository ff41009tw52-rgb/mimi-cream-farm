# 悠悠水族箱：老師作品收件設定

前端已加入「更多 → 拍照分享」。收件服務未設定時，學生仍可拍照、預覽、下載，但不能送出，畫面會清楚說明尚未開放收件。

## 老師只需設定一次

1. 用**準備收學生作品的老師 Google 帳號**開啟 https://script.google.com/home/start ，新增一個**獨立 Apps Script 專案**，名稱可用「悠悠水族箱作品收件」。不要覆蓋原本生態池等服務。
2. 把本目錄 `Code.gs` 的完整內容貼入專案。儲存，選擇函式 `setupAquariumPhotos`，按「執行」，完成 Google 的授權。程式會建立私人「悠悠水族箱－學生作品」資料夾，依班級建立子資料夾；通知預設寄給執行設定的 Google 帳號。
   - 如需指定另一個信箱，在「專案設定 → 指令碼屬性」加入 `TEACHER_EMAIL`，值為收件信箱，再執行設定。
   - 若使用手動管理權限範圍，可在設定中開啟顯示 `appsscript.json`，貼入本目錄的範本。
3. 按「部署 → 新增部署作業」，類型選「網頁應用程式」。**執行身分：自己；誰可以存取：任何人**。學生不需登入。若學校網域禁止匿名網頁應用程式，請交由網域管理員處理，不能改成要求學生交出帳密。
4. 複製部署網址（`https://script.google.com/macros/s/…/exec`），提供給維護者，填入 `assets/aquarium-v06/photo-config.js` 的 `endpoint`；重新產生單檔版並部署網站。不要使用 `/dev` 測試網址，也不要把老師信箱或資料夾 ID 放進公開程式碼。
5. 用實際學生平板從原遊戲網址交一份測試作品，確認私人 Drive 資料夾中的圖片可讀、照片資料正確、信箱收到通知。未完成這次實機收件前，不應宣稱服務已正式開通。

## 已實作的行為

- 只拍目前魚缸，不開相機；照片含魚兒、布置、魚缸名稱、班級、座號、臺灣拍攝時間及選填的布置想法。隱藏金幣、飼料、操作按鈕、選取框和提示特效，不更動遊戲進度。
- 班級最多 12 字；座號 1–99；想法最多 120 字。只收這些資料，不收學生姓名、email 或帳號。
- 照片及表單獨立存於 IndexedDB，不與遊戲存檔共用空間。裝置不支援持久儲存時仍保留於本次頁面記憶體，關頁可能遺失；應先下載保存。
- 以 CORS simple POST（`text/plain`）傳 JSON，讀取 Apps Script 的 JSON 確認。絕不使用 `no-cors`、郵件軟體開啟成功或空白回應來推斷已收件。Google 登入頁、CORS 錯誤、超時與拒收都保留照片並允許重試。
- 收件服務驗證 PNG 簽章、尺寸與最大 1.5 MB，使用固定老師端目的地，不接受學生提供信箱或資料夾；資料夾與作品不開放公開連結。
- Drive 寫入並確認檔案大小後才回覆 `ok` 與收件編號。用穩定提交 ID、內容雜湊與伺服器鎖避免連按或網路重試產生重複照片。同編號不同內容拒收。失敗重試鎖定原資料，需修改時可按「修改資料」建立新提交。
- 每天最多 150 份新作品、每班每座號每天 6 份；重試既有作品不占次數。這些是匿名服務的流量限制，不是學生身分驗證；有人冒填班級座號仍可能耗用額度，需要更強驗證時另加老師發放的作業憑證。
- 通知信附 PNG 原圖與私人 Drive 連結。通知寄送失敗或信件配額不足時，已存好的作品仍算收到，回傳 `notification: pending`；老師可直接從 Drive 查看。重試同一份作品時會再嘗試通知，成功後不重複寄送。Google 配額視帳號而異，免費帳號可能先達每日寄信上限；不要依通知信數量認定作品總數。
- 收件索引保留 7 天後清理，原照片不自動刪除。過期索引可從原檔名和描述恢復以避免重複存圖。老師可自行整理或刪除學期作品。

## 驗證與限制

`node tests/aquarium-v06/photo-share.test.cjs` 驗證前端確認與失敗分支，以及以 Google 服務替身驗證真正的 `doPost`：儲存、重試、內容衝突、限額與信件失敗。

模擬測試不會代替 Google 帳號授權、匿名部署或跨來源實機收件測試。目前工具無法替老師建立／部署 Apps Script 專案；需要老師完成上述授權後提供 `/exec` 網址。

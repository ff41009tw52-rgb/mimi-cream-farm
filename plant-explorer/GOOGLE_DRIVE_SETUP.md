# 植物探索家：學生拍照直接上傳 Google 雲端硬碟

## 目前狀態
- 學生端已移除「老師提供的交件碼」。
- 拍照後可以從照片區直接按「傳送照片與觀察紀錄給老師」，程式會先安全存於本機，再嘗試上傳。
- **尚未啟用真實收件端**：`plant-explorer/config.js` 的 `receiverUrl` 目前留白。空白時作品只會留在學生裝置，不會到教師 Google Drive。**請勿誤以為已交件。**
- 收件端來源在 `plant-explorer/drive-receiver.gs`。必須以指定帳號部署，才會儲存到該帳號的「我的雲端硬碟」。

## 教師初次部署（以 zx5566zero@apps.ntpc.edu.tw 登入）
1. 在 Apps Script（script.google.com）新增一個專案，命名「植物探索家收件」。
2. 將 `plant-explorer/drive-receiver.gs` 的完整內容貼入預設的 `Code.gs`，儲存。
3. 右上方「部署」→「新增部署作業」→ 類型選「網頁應用程式」。
4. **執行身分：「我」**（以上述學校帳號執行）。存取權限選擇 **「所有人」**（若學校政策不允許，需改用有帳號驗證的方案；不能假裝匿名上傳可用）。
5. 完成 Google Drive 存取權授權；取得以 `https://script.google.com/macros/s/...` 開頭、以 `/exec` 結尾的網頁應用程式 URL。
6. 編輯 `plant-explorer/config.js`，將 `receiverUrl: ''` 填入完整部署網址；部署至 GitHub Pages。
7. 開無痕視窗（不登入 Google）、以學生手機或平板測試「班級、座號、5項觀察、照片、直接傳送」流程。確認網頁顯示「老師已收到」，並在該學校帳號的 Google 雲端硬碟「我的雲端硬碟」中出現 **植物探索家_學生觀察作品**。
8. 必須再測試 1 次：上傳時斷網，檢查照片是否仍保留在「我的觀察圖鑑」，能否使用「補傳尚未交出的作品」重試。

## 實際儲存內容
- 教師雲端硬碟 `植物探索家_學生觀察作品/` 下，每筆作品一個私人資料夾。
- 資料夾名稱包含班級、座號／組別、植物名稱和唯一交件編號。
- 每筆作品包含 `照片1.jpg` 至 `照片3.jpg`、`觀察紀錄.json`、`收件完成.txt`。
- Google 雲端硬碟不需要公開「檢視權限」；學生只透過 **僅可上傳** 的網頁應用程式送交。班級與座號請勿替換成學生姓名。

## 安全與限制
- 不設「老師提供的交件碼」代表公開收件網址可能被第三方濫用；此收件端不提供列出或下載他人作品的功能，但公開上傳仍需定期查看配額、垃圾檔與異常交件。
- 作品僅在學校帳號部署並執行時，才會存入指定學校帳號的硬碟，**學生端顯示收件地址不等於完成設定**。
- 本版使用隱藏表單 + iframe 的方式嘗試取得收件回執，避免直接跨網站 fetch 的 CORS 限制。Google 的 iframe 安全限制與學校 Workspace 政策可能造成無法確認；若手機/平板測試不通，應停止宣稱可自動上傳，改用可正式驗證的後端服務。
- 逾時／失敗時不會標示「老師已收到」，只會標為「結果待確認」，保留照片並允許用相同交件編號重傳；收件端具備基本重複收件保護。
- 對外公開網頁前，應確認學校個資政策、實際 Google Drive 共用設定、App Script 的發佈權限，以及學校資訊組是否允許匿名收件。
- 不可將 OAuth Token、Google 登入密碼或雲端硬碟存取金鑰寫進公開 GitHub 檔案。

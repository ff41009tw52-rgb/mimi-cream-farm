# 植物探索家：學校 Google Drive 收件設定

網站已可本機保存、編輯、備份及下載照片。以下步驟未完成前，網站明確顯示「老師收件尚未啟用」，不會假裝已上傳。

指定收件帳號：**zx5566zero@apps.ntpc.edu.tw**。目前 ChatGPT 連線的個人 Google 帳號不是此帳號，請勿用個人帳號代部署。

1. 使用指定學校帳號登入 Google Apps Script，建立獨立專案「植物探索家收件」。
2. 將同資料夾的 `DriveReceiver.gs` 貼入 `Code.gs`。
3. 執行 `setupPlantReceiver`，以學校帳號授權。程式會檢查帳號並建立私人的「植物探索家_學生觀察作品」資料夾。請保留執行紀錄中的資料夾網址。
4. 在「專案設定 → 指令碼屬性」新增 `CLASS_CODE`，設定自行選擇的交件碼，課堂告知學生。不要把交件碼或 OAuth 權杖放到 GitHub。`FOLDER_ID` 由設定函式自動建立。
5. 「部署 → 新增部署作業 → 網頁應用程式」：執行身分為自己；存取權須讓學生可使用（免登入收件需允許「所有人」）。這僅開放交件網址，**不需要公開硬碟資料夾**。學校管理員若不允許這種部署，先洽管理員確認；不要以個人帳號代替指定帳號。
6. 取得 `/exec` 部署網址，填入 `config.js` 的 `receiverUrl` 並提交 GitHub。不要用 `/dev` 測試網址。
7. 真正啟用前，以學生使用的 iPad／Android 平板測試 1 張及 3 張照片：填班級組別 → 本機儲存 → 輸入交件碼 → 傳給老師。確認硬碟有照片、觀察 JSON 和「收件完成.json」，且前端顯示老師已收到。
8. 測試網路中斷／重試：相同 `uploadRevision` 不會重複建立已完成收件；編輯後再交會保留為新的版本。無法讀取確認回覆（包括跨來源或學校政策阻擋）時，網站保留本機作品，顯示結果待確認，不宣稱成功。

## 資料與限制

- 每筆最多 3 張 JPG，最長邊 1200px，單張編碼上限約 1,000,000 字元。
- 每天最多 300 次新的收件嘗試；包含部分失敗重試，保護帳號配額。可視授課需要在程式內調整。
- 每份交件是一個「收件_版本編號」資料夾，內含班級_組別_植物名_序號.jpg 及觀察資料 JSON。硬碟不對學生公開，不提供匿名列出／刪除他人作品的功能。
- 交件碼是課堂共用收件驗證，並非學生身分認證。請定期更換。需要嚴格學生身分／老師審核／全校共用圖鑑時，應另建登入與存取權限。
- 本機刪除不會刪除老師硬碟的副本。修改本機紀錄後須重新交件。
- Apps Script 的配額、學校網域政策及瀏覽器跨來源回覆，都需用指定帳號部署後實測。目前未宣稱已完成真實硬碟上傳測試。

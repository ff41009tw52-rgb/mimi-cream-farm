# 班級彩繪水族館 V2（USB 實物投影機版）

## 檔案
- `/class-aquarium-v2.html`：可獨立開啟的掃描／水族館頁面；不影響 V1 `class-aquarium.html`。
- `/aquarium-v2/templates/clown.svg`：A 小丑魚型
- `/aquarium-v2/templates/butterfly.svg`：B 蝴蝶魚型
- `/aquarium-v2/templates/puffer.svg`：C 河豚型
- `/aquarium-v2/templates/shark.svg`：D 鯊魚型

## 流程
1. 列印 A4 橫式著色紙，**100% 原尺寸列印**，不要裁邊、剪魚或遮住黑色方塊。
2. USB 實物投影機連接電腦，使用 Chrome 或 Edge 透過 HTTPS 的 GitHub Pages 開啟網頁。
3. 選魚形、選 USB 攝影機、開啟鏡頭並授予權限。攝影機需提供可供瀏覽器讀取的 UVC 或相容驅動。
4. 學生上色後，紙張平放於攝影機下，四個定位黑方塊完全入鏡，拍一張照片。
5. 依照左上、右上、右下、左下順序，拖曳 ①②③④ 對準四個黑方塊中心，點擊「擷取魚身並預覽」。
6. 檢查預覽後新增作品，切換「全螢幕水族館」，將電腦影像顯示到教室大螢幕。
7. 下課前建議點「匯出作品備份」，將 JSON 檔安全保存在學校電腦的指定資料夾。

## A4 模板共同規格
- 紙張：297 × 210 mm（A4 橫式）。
- 繪圖座標：800 × 566。
- 黑色方塊：20 × 20 座標單位（約 7.43 × 7.42 mm）。
- 定位方塊中心依序：左上 (40,40)、右上 (760,40)、右下 (760,526)、左下 (40,526)。
- 魚身可裁切範圍：x=110～720、y=130～439。四種魚有不同遮罩路徑；不可互換模板類型。
- 掃描：攝影機畫面由瀏覽器取得；先手動定位四角，再計算平面透視轉換，將魚形外的像素轉成透明 PNG。
- 目前沒有自動偵測黑色方塊與跨裝置同步。

## 技術架構
```text
[學生 A4 畫紙]
     ↓ USB UVC 攝影機 / 照片匯入
[GitHub Pages：class-aquarium-v2.html]
     ├── 選擇四魚形 / 打開攝影機 / 拍照
     ├── Canvas 四角手動校正 → 透視映射 → 遮罩 PNG
     ├── IndexedDB：本機保存魚圖與動畫資料
     ├── 備份 JSON 匯出／匯入
     └── Canvas 水族館動畫 → HDMI 大螢幕
```

V2 是**單一電腦本機版**。若要讓學生平板上傳到教師端，需開發獨立的後端 API、作品儲存、老師的審核／刪除權限、圖片尺寸與類型限制，以及合理的跨來源通訊設定。GitHub Pages 只能負責靜態前端，不能直接接收學生上傳並永久儲存至伺服器。

## 測試與已知限制
- 必須以 HTTPS 網址開啟才可取得相機權限（localhost 等安全環境例外）。
- USB 存在不代表可直接當 webcam；需裝置能被作業系統辨識成影像輸入裝置。
- 角度很斜、黑色定位方塊遮蔽、反光、陰影或模糊照片可能導致裁切偏移，請調整四角或重拍。
- 無 USB 攝影機時可使用圖片檔匯入。
- 本機作品優先存於 IndexedDB，不同瀏覽器或電腦不共用；瀏覽器清除網站資料也可能刪除作品。
- 如經由共用電腦進行活動，應避免輸入學生姓名，定期刪除或妥善保管備份，並遵守學校資料保護規範。
- 網頁程式碼已通過 JavaScript 語法檢查，尚未以教室 USB 實物投影機完成實機測試。

## 下一階段建議
1. **小班實測**：一張各魚形模板，用不同顏色、不同光照測試擷取準確度。
2. **加速操作**：鏡頭位置固定後，保留四角對位與快速拍攝模式；再評估自動定位方塊。
3. **全班同步**：加入雲端圖片儲存及教師展示端的同步（不使用公開寫入無認證的資料 API）。
4. **教師管理**：新增作品審核、重複上傳控制、清除本次課堂資料，驗證跨裝置同步後再納入既有自然首頁。

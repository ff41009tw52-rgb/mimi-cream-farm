# Farm Rounded

Game-text subset of jf open-huninn 2.1 by justfont, distributed under SIL OFL 1.1 (see OFL.txt).

Source: https://github.com/justfont/open-huninn-font/releases/tag/v2.1

Modifications: subset to the characters in 12-2.html and gameplay-v3.js plus printable ASCII; WOFF encoding; renamed family and PostScript names to Farm Rounded / FarmRounded-Regular. Original copyright and license metadata retained. Unknown player-entered characters fall back to system fonts. The source font is not needed at runtime.

When adding new game copy, regenerate this subset if it adds characters outside the bundled character map.

# 12.html 視覺資產整合

此目錄是 `12.html`（四季農莊：島嶼物語）的視覺資產 Source-of-Truth。

## 安全原則
- 所有修改只在 `farm12-visual-assets` 分支進行。
- `main` 不修改。
- 新圖片失敗或尚未上傳時，`12.html` 必須保留舊 Emoji / SVG fallback，避免遊戲壞掉。
- 已核准的成熟植物圖不重新生成或覆蓋，除非使用者明確要求。

## 目錄規劃
- `crops/mature/`：一般成熟作物
- `crops/legendary/`：傳說成熟作物
- `crops/seedling/`：專屬幼苗
- `crops/pre-mature/`：成熟前 / 花果期
- `tools/`：澆水壺、灑水器、剪刀、辣椒水
- `pests/`：害蟲與雜草
- `fertilizer/`：氮、磷、鉀肥
- `protection/`：防蟲網、防風網
- `field/`：乾濕土壤與田地狀態
- `ui/`：功能型 SVG / 小型 UI 素材

## 已確認成熟作物
一般作物：地瓜葉、青江菜、芭樂、空心菜、絲瓜、芒果、筊白筍、芋頭、文旦、白蘿蔔、高麗菜、草莓。

傳說作物：黃金仙桃、水晶寶石西瓜、巨無霸南瓜、初雪白草莓。

## 已確認生長階段素材
- 短期幼苗：地瓜葉、青江菜、空心菜、筊白筍、白蘿蔔
- 三階段：芭樂、絲瓜、芒果（幼苗 + 成熟前 + 成熟）
- 其餘目前安全退回「舊幼苗 / 成熟」模式，之後補圖不需重寫核心邏輯。

## 已確認其他素材
- 菜蟲
- 雜草
- 澆水壺
- 自動灑水器
- 園藝剪刀
- 辣椒水噴霧

## 圖片效能目標
- 田格 / 工具 / 害蟲：128–256 px
- 商店 / 圖鑑成熟作物：最高 512 px
- 優先 WebP + 透明背景
- `object-fit: contain`
- 非首屏圖片 lazy loading

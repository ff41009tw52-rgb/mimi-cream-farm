## Rollout guardrails

1. Do not modify crop prices, days, season rules, pests, weeds, typhoon, quests, economy, save format, or 365-day scoring as part of the visual migration.
2. Do not remove the old Emoji/SVG path until the corresponding image asset is present and has passed a visible test.
3. Use image assets through the manifest instead of hardcoding paths throughout components.
4. Legendary crops keep CSS glow/pulse effects separate from the base image.
5. Farm tile art should use 128–256 px images; shop/encyclopedia views may use 512 px images.

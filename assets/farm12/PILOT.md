# Farm 12 Visual Pilot

此分支僅供可玩測試，不直接合併到 `main`。

## 版本分工
- `12.html`：原版對照頁，保持不修改。
- `12-1.html`：新版專用入口；後續所有視覺改版都在此版本驗證。
- `farm12-pilot.html`：歷史素材對照頁；停止維護，不再作為驗收入口。

`12-1.html` 會在瀏覽器中讀取原版 `12.html`，再套用新版視覺掛載點，因此原始程式仍可作為安全 fallback。新版另使用 `farm_tycoon_save_v2_12_1` 存檔 key，避免測試進度覆蓋原版存檔。

目前只保留 `12-1.html` 作為使用者農場測試入口；測試資金最低 100000，並確保所有作物種子在背包中至少各有 1 包。

## 第一批已接入的圖片流程
1. 青江菜：幼苗 → 成熟（二階段）
2. 芭樂：幼苗 → 花果期 → 成熟（三階段）
3. 黃金仙桃：成熟圖 + 傳說 CSS 發光特效
4. 上述三種作物同步套用到種子袋與收成飛行動畫；未納入圖片流程的作物保留安全 fallback。

## 短期作物二階段
1. 青江菜：剛發芽幼苗 → 成熟株（沿用既有 Pilot atlas）。
2. 地瓜葉：幼嫩扦插新芽 → 心形葉片繁茂藤叢。
3. 空心菜：子葉與初生真葉 → 狹長葉與中空莖成熟株叢。
4. 筊白筍：早期禾本科嫩芽 → 基部膨大的白色可食莖。
5. 白蘿蔔：子葉與最初鋸齒真葉 → 白色膨大根與成熟葉叢。

地瓜葉、空心菜、筊白筍與白蘿蔔已補齊 256×256 真透明 WebP 成熟素材；四種作物在成熟時不再回退 Emoji，種子袋、田格與收成飛行動畫共用相同圖片流程。

## 三階段作物批次
1. 芭樂：沿用既有 Pilot atlas 的幼苗 → 開花／幼果 → 成熟。
2. 絲瓜：新增專屬幼苗 → 黃花與小幼果 → 成熟果實。
3. 芒果：新增專屬幼苗 → 花序與綠色幼果 → 黃紅成熟果。

絲瓜與芒果六張素材皆為 256×256 透明 WebP；三階段切換門檻與芭樂一致，成長進度 38% 起顯示開花／幼果期，達 100% 顯示成熟。

## 第四批一般長期作物
1. 芋頭：心形初葉幼苗 → 大葉生長與球莖膨大 → 成熟芋頭。
2. 高麗菜：子葉與初生真葉 → 葉片展開並開始結球 → 緊實成熟葉球。
3. 草莓：早期三出葉 → 白花與綠色幼果 → 紅色成熟果。
4. 文旦：柑橘幼樹 → 白花與小綠果 → 黃綠成熟文旦。

本批十二張素材皆為 256×256 真透明 WebP，已同步登錄於 `farm12-assets.js`、`farm12-pilot.html` 與 `12-1.html`。階段門檻維持 38%／100%，不變更任何價格、生長天數或遊戲規則。

## 傳說作物完整生長階段
1. 黃金仙桃：新增金紋幼苗與桃花／金綠幼果期；成熟圖沿用原 Pilot atlas 核准版本，僅擷取為獨立 WebP。
2. 水晶寶石西瓜：水晶紋幼苗 → 黃花與寶石幼瓜 → 透明水晶成熟西瓜。
3. 巨無霸南瓜：金紋幼苗 → 黃花與金橘幼果 → 發光金橘巨型南瓜。
4. 初雪白草莓：霜紋幼苗 → 白花與淡色幼果 → 珍珠白成熟草莓。

傳說作物共十二個階段素材，皆為 256×256 真透明 WebP。幼苗、中期、成熟使用漸進式 CSS glow／pulse／sparkle，越接近成熟效果越強；不改動作物數值與核心遊戲規則。

## 獨立素材收尾
青江菜成熟圖與芭樂三階段已從原 Pilot atlas 無損擷取為四張獨立 WebP，保留原生 56×56 像素與透明度，不重新生成或放大重繪。青江菜幼苗沿用既有剛發芽圖，素材清單已修正到實際路徑。兩個測試頁的所有作物階段皆使用獨立圖片；舊圖集保留作為歷史對照。

## 安全規則
- 圖片或掛載點失敗時顯示錯誤頁，不修改 `12.html`。
- 未納入新版圖片流程的作物保留原 Emoji / SVG fallback。
- 不修改價格、生長天數、季節、蟲害、雜草、颱風、任務、經濟與核心遊戲規則。
- 使用者完成測試並確認後，才合併回 `farm12-visual-assets`。
- `farm12-visual-assets` 完整驗收後，才考慮合併至 `main`。

# 115 學年度四年級國語、數學遊戲規劃

依使用者提供的民安國小 115 學年度教科書選用表：**四年級國語康軒版、數學南一版**。此文件只列課次、單元和原創遊戲構想，不含教科書正文、圖片或題庫；實作前仍須與當期教材核對。

| 8 整數四則 | 算式修復站 | 括號與運算順序 |

**避免錯置單元：** 現有首頁的「幾何建築師」原主題為周長與面積，這是南一**四下第7單元**的主要內容；四上應先做三角形。原「分數橋梁工程隊」若主打**等值分數**，則適合四下第8單元；四上分數應先做真假與帶分數互換、分數數線。

## 優先開發順序

1. 接近第一學期中段課程：數學「角度遊樂園」、「三角形工地」、「披薩餐廳」；國語「文字料理屋」、「建築資訊修理站」、「閱讀偵探社」。
2. 補充基礎：國語「國字拼裝工廠」、「錯字捕捉隊」；數學「大數銀行」、「超級市場」、「除法配送站」。
3. 每款優先有單人練習、可放大的題目字體、操作回饋與錯題提示；不強制登入。
4. 開發採**原創情境、程式與題目**，不直接複製出版教材或其他遊戲的美術與題庫。
5. 自然首頁不修改；遊戲尚未開發前，國語、數學卡片維持「即將推出」。

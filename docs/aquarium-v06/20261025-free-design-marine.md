# V0.6 自由造景與海水缸

基底是已合併 PR #83 的 main；原 26 項成就合計 1,415 金幣與特殊配色維持。原 V0.6 頁面、三個主按鈕與四種蝦蟹母圖保留。

## 資料與造景

- `design-content.js` 加入蓋斑鬥魚、十五種海水魚、十六種布置與五項造景成就。原物種及布置 ID 不變，總計 35 種居民與 40 種布置。
- `design-art.js` 是新內容正式向量母圖；商店、魚缸、圖鑑及觀察共用。原有魚類及布置仍交給原繪圖器。每種布置五款配色，依植物、木材、石材及柔和裝飾選色；材質以保留亮暗的像素轉色處理，最多快取 96 個表面，不在每一動畫幀重新轉色。
- 舊 `normX`、`snapIndex`、`lane` 不改寫。編輯後另存 `posX`、`posY`、`color`、`rotation`、`scale`、`flip`、`z`。沒有垂直位置的舊布置仍使用原本計算式，位置不重排。
- 四方向微調、滑鼠／觸控拖曳、底部對齊、60–140% 縮放、旋轉／翻轉、圖層及最多三十步復原整合在編輯工具列。下拉選取可處理完全重疊物件。魚始終繪在布置上方，避免永久遮蔽居民。所有設計交易走原保存日誌；底砂獨立換色，不作漂浮物件。
- 每缸最高 25 件布置。重畫背景只發生於布置或尺寸改變，仍使用原單一動畫循環。

## 魚缸與等級

每型最多三缸，以 `habitat` 分類；缺少欄位的歷史存檔預設淡水。海水缸解鎖為等級 5／800、7／1,600、9／2,600。各缸居民、布置、底砂與升級獨立；金幣、三種飼料、等級、圖鑑與成就共用。商店、購買確認、跨缸移動與存檔驗證均檢查生物／魚缸類型。

新等級門檻為 1,800／2,800／4,100／5,700 XP（6–9 級），保留前五級及歷史 XP；原五級封頂玩家會依已有 XP 升級。舊驗證器使用原等級規則，V0.6 轉接層處理新增等級，避免舊高 XP 存檔被拒。

## 一次性成就差額

只依 `rewardPaid` 和本機獎勵帳本中的實付金額補發。原 26 項已領取但沒有金額的歷史紀錄，實際支付額無法可靠區分 PR #83 前後，因此保留領取旗標與特殊配色，不推估差額、不額外發錢。已在較早更新中完成補發的帳本繼續保留，不追扣玩家金幣。

已知舊額的差額與新領獎仍經寫入前日誌、保存快照和失敗回滾；帳本取較大已付金額，重新載入、還原舊存檔及交易中斷不會重複補發。五項造景成就維持手動領取且僅一次。

## 科學命名來源

蓋斑鬥魚學名沿用臺灣魚類資料庫：<https://fishdb.sinica.edu.tw/taxon/381391-fishdb>。透紅小丑魚採 WoRMS 接受名 `Amphiprion biaculeatus`（原名 `Premnas biaculeatus`）：<https://www.marinespecies.org/aphia.php?p=taxlist&tName=Amphiprion>。其餘圖鑑提供 FishBase 物種資料連結；真實飼養與本遊戲三種飼料的簡化明確分開。

## 自動驗證

保留原 schema、教學、餵食、成就、免費送養與多魚缸回歸。新增 `design.test.cjs` 驗證三種畫面尺寸、舊位置不變、25 件容量、每件獨立配色、變形／復原／保存、一次補發與日誌回復、六缸購買及類型限制、十六種新魚繪圖與構造資料。原 Chromium／WebKit CI 都執行此套件。

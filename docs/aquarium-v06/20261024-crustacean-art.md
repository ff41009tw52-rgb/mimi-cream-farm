# V0.6 蝦蟹美術整合

維持 `aquarium-v0.6.html`、原存檔格式與既有遊戲系統；不新增版本、頁面或玩法。

## 正式美術來源

四種生物共用 `assets/aquarium-v06/crustaceans.js` 中各自的 Canvas 向量母圖。沒有額外圖片下載、臨時素材、字型依賴或隨機繪圖。原本十五種魚仍交由既有魚類繪圖器處理。

| 生物 | 保留的美術方向與辨識重點 |
| --- | --- |
| 黑殼蝦 | 黑褐、炭灰與透明暖色層次，清楚的頭胸部、分節腹部、長觸角、步足、腹面游泳足與尾扇。 |
| 藍蝦 | 同樣完整的蝦類構造，以冰藍高光、鈷藍甲殼、藍紫腹側與斑點形成獨立材質。 |
| 迷你蜘蛛蟹 | 小型中央甲殼、四對細長關節步足、細小螯與眼柄；缸內維持小型感。 |
| 拳擊蟹 | 暖沙色甲殼、較粗步足、清楚眼柄與兩隻帶細毛的螯。沿用原圖鑑河口毛螯型定位，不畫成攜帶海葵的海水拳擊蟹。 |

## 整合方式

- 商店、購買確認、圖鑑、配色收藏、個體資料、更多資料、管理與居民列表均使用同一 `previewFish`。蝦蟹預覽以 480×280 畫布呈現，依母圖邊界等比例置中。
- 圖鑑加大圖片；資料卡與管理介面新增同源圖片。未解鎖的商店商品仍清楚顯示外形，但原購買限制不變。
- 科學觀察使用相同母圖、完整放大範圍和既有構造選取；內部鰓與腹部維持透視示意說明。
- 魚缸顯示尺寸是暫態計算，不寫回生物大小或成長紀錄。點選範圍與實際轉向、關節外形一致；螃蟹不套用魚類轉身壓縮。
- 行走步態與靜止的觸角／小螯動作分離；停留不滑動、不持續踏步。蝦類沿用短游、避讓及底餌行為。
- 固定向量路徑快取；會隨動作變化的觸角路徑不進快取，避免長時間累積。

## 相容與回歸

存檔 key、schema、物種 ID、價格、解鎖、成長、餵食、金幣、免費送養及轉缸規則均未變更。「全部收取」仍移除，居民數量與升級按鈕間距沿用上一個修正。

`crustacean-motion.test.cjs` 檢查停留、行走、短游、抵達目標、存檔欄位不變與魚類原繪圖器轉交。`crustaceans.test.cjs` 在五種尺寸檢查購買／命名、圖片清晰度與無裁切、各介面母圖一致、觀察構造、存檔、成就、轉缸與免費送養；由原 CI 同時在 Chromium 與 WebKit 執行。原有其他 V0.6 與 V0.5 回歸套件保留。

## V3.0.0 驗收紀錄

測試日期 2026-11-15。以 Chromium 153 無頭模式、兩個同源頁籤和 1920 × 1080 視窗測試。自動掃描使用 Canvas 產生不同畫面並送入 MediaStream，影像擷取、Web Worker、PNG、IndexedDB、BroadcastChannel 和展示均跑正式程式。

| 驗收項目 | 實測結果 | 狀態 |
| --- | --- | --- |
| 四種魚形、旋轉和透視 | 48/48 正確。涵蓋四種著色、17° 旋轉、倒轉、直式、梯形、位移、亮度、陰影、遠距、模糊與非標記處遮擋 | 通過 |
| 低信心防誤收 | 12/12 拒收，含空場或一角／四角標記遭遮蔽的圖片 | 通過 |
| 透視與透明擷取 | 在 896 × 704 影像的最大投影誤差 0.29 px；48 張 PNG 的四個外角均透明 | 通過 |
| 顏色取樣 | 每張魚身取四點，比對同張輸入影格的 RGB，各色道最大差值 8/255 | 通過 |
| 重複掃描與換紙 | 第一張持續放置、短暫遮一角再露出仍為 1 筆，移開並等到就緒後放第二張，增為 2 筆 | 通過 |
| 即時同步 | 2 次入場，從建立保存紀錄至展示端 PNG 解碼分別 12、23 ms，低於 500 ms | 通過 |
| 重開與管理 | 展示頁重新載入恢復 2 筆；逐張刪除、確認清空及兩個動態設定有效 | 通過 |
| 手動備援 | 照片可自動帶出對位與魚種、預覽後加入。遮角影像可進手動魚種及定位流程 | 通過 |
| 攝影機錯誤 | 模擬 USB 影像軌結束、拒絕授權，兩種提示與重試入口可見 | 模擬通過 |
| 直播 40 尾 | 1920 × 1080 展示，3.5 秒更新率取樣為約 55 FPS；全螢幕進出成功 | 測試環境通過 |
| PDF | 4 頁 297 × 210 mm，逐頁渲染檢查魚身與四角標記 | 通過 |
| 教室 USB、印表機、實體雙螢幕 | 教室設備與真實紙張需現場驗收 | 待驗 |

辨識測試使用全部 60 張合成樣本，測試角度和亮度以固定條件生成。實際教室的反光、感光元件、對焦、鏡頭畸變、印刷墨量及壓縮強度仍需現場驗證。幀率為這次測試環境的量測值。
